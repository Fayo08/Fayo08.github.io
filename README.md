# oyende-favour

Portfolio of Oyende Favour (Favour Oyende), full-stack developer in Calgary.

Plain HTML, CSS and JavaScript, no build step. GitHub Pages serves `index.html` from the root of `main`.

- **Hero:** an editor that types its own source, compiles, then renders the name. The rain behind it is made of project names.
- **Selected works:** a component tree; click a `<Work />` to open it.
- **Works:** a 3D cube of six projects driven by a working command line (`help`, `ls`, `open <name>`, `run lagos-life`).
- **Code snippets:** real code from InStock and TalentTrace.

To add or edit a project, change the `WORKS` list at the top of `app.js`. Images live in `media/`.
